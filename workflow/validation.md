# Validation

Validate frozen dependency installation, lint, tests, import and demo from a plain clone without initialized submodules. Validate developer routing and exact gitlink in a separate recursive clone.

For models: freeze splits/seed/preprocessing, choose thresholds on calibration only, report business and model metrics on untouched test data. Label synthetic results separately. Measure p50/p95 on specified hardware and volume; do not extrapolate deployment claims silently.

Record executed commands, environment, exit codes and unresolved limits.
