# Solution Design

Adapt the design and decision templates. Identify data ingestion, preprocessing, inference/rules, review action and reporting. Define schemas, invalid-input behavior, ownership and deployment boundary.

Compare no-AI/rule baseline with alternatives. Record latency/cost/error tradeoffs and data rights. `.framework` is a development-only reference; runtime must not access it.
