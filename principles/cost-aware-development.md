# Cost-Aware Development

Optimize accepted quality per completed task, with tests and rework as constraints. Read only routed context and reuse verified outputs.

Separate development AI cost from runtime API and infrastructure cost. Record unavailable telemetry as unknown/null; label estimates. Prefer rules, compact local models, caching and batches before paid runtime calls. Price references need date, currency and source.
