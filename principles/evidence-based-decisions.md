# Evidence-Based Decisions

Observed requires a source or reproducible experiment. Assumed requires an explicit scenario and units. To Validate requires an owner or next verification action.

Record dataset/version/split, configuration, commands, environment and metrics. Do not call target KPIs achieved results. Do not use test labels to tune thresholds. Keep failure cases and rejected experiments.
