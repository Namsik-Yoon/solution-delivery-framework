# Git Convention

Use small coherent commits: `docs:`, `feat:`, `fix:`, `test:`, `chore:`. Never rewrite published history or move a released tag without explicit direction. Preserve user changes.

One business problem per repository; one central framework. Pin its exact gitlink and version receipt. Upgrade via an explicit reviewed decision. GitHub issues and decisions hold work state across devices.
