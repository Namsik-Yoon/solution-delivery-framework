# Data Governance

Record publisher, canonical URL, license/terms and check date, acquisition method, version, checksums, schema, allowed use and redistribution constraints. Project code license never replaces dataset rights.

Use official access routes; do not bypass login/forms/competition terms. Document the minimum manual steps and automate only lawful local preparation. Do not commit large data, weights or derived images.

Raw data is immutable; preprocessing/splits are versioned and reproducible. State proxy gaps, leakage risks, prohibited features and rights for derived artifacts. Separate synthetic fixtures from public datasets.
