# Documentation Convention

Keep one purpose per file. Use short titles, links and concrete executable commands; include `title`, `version`, `read_when`, `skip_when`, `priority` metadata in framework Markdown.

Observed/Assumed/To Validate labels apply to important business, cost and performance claims. Source facts with dated primary links. Distinguish configured, executed and verified. Customer docs must be self-contained without framework initialization.
